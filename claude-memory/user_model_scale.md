User models in **1/48 scale**. When suggesting kits, masks, or reference
material tied to a specific scale, default to 1/48. Where no 1/48 option
exists, prefer the next larger scale available (e.g. 1/32) over a smaller
one like 1/72.

**Why:** user corrected this explicitly (2026-08-20) after seeing a 1/72
reference surface during Bottisham Four research — stated preference,
not inferred.

**How to apply:** applies across [[model-masks]] project work generally —
mask cutting, kit reference searches, model subject research — not just the
Bottisham Four task it came up in.
